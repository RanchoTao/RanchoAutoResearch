# Statistical analysis

ARC-009 is a finite-universe feasibility census, not a sampled causal-effect
estimate. The primary statistic is the exact PASS-A count among all 103 frozen
Class A cells, evaluated against the preregistered thresholds 60 and 70.

- PASS-A: 47/103 (45.6%).
- PASS-B: 29/103 (28.2%), descriptive only.
- FAIL-TRADEOFF: 27/103 (26.2%).
- Absolute PASS-A gain over ARC-008: +32 cells.
- Relative PASS-A increase over ARC-008: +213.3%.
- Numerical failure: 0/103.
- Boundary solution: 0/103.

Because the full frozen universe was evaluated, a confidence interval for the
103-cell count would obscure the actual decision rule and is not used. There
is also no outcome or causal effect in this ARC to bootstrap.
