# ARC-20260825-5060-002

Independent-run red-team validation of the training-time decline in
single-layer-deletion robustness. This ARC uses PolyPythias pretraining runs;
evaluation/data shards are resampling controls and are never counted as
independent replications.

The frozen design and decision gates are in `reports/`. Raw checkpoint-level
outputs are written incrementally under `experiments/raw/`.
