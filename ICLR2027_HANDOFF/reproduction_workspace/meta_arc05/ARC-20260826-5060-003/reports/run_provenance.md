# Independent-run provenance

## Source and independence

PolyPythias accompanies *Stability and Outliers across Fifty Language Model
Pre-Training Runs* (van der Wal et al., ICLR 2025; arXiv:2503.09543). The paper
reports 45 additional pretraining runs created by varying initial conditions.
The EleutherAI model cards explicitly distinguish combined `seed1`-`seed9`
runs from `data-seed` and `weight-seed` controls. The combined runs used here
therefore vary both initialization and data order. Evaluation seeds are not
counted as training runs.

Authoritative sources:

- https://arxiv.org/abs/2503.09543
- https://github.com/EleutherAI/pythia
- https://huggingface.co/EleutherAI/pythia-160m-seed9

All new run configs were fetched from their main revisions before deletion
evaluation. After removing the transient `_commit_hash`, seeds 6-9 had the same
canonical config SHA-256:
`12236d149eb6b23da57a08063bd626ed368068f6f7cd96d091bfd4350bf49ec2`.
