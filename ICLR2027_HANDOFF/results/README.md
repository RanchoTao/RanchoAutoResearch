# Result archive

This directory groups raw, processed, matching, and summary outputs by ARC. The complete original layouts also exist in `../reproduction_workspace/` and `../logs/arc_records/`.

Validity is defined by `../logs/EVIDENCE_VALIDITY_MAP.md`:

- VALID headline evidence: ARC-003, ARC-004, qualitative ARC-005, ARC-006R, ARC-007R, ARC-011.
- VALID matching provenance only: ARC-006 target assignments/diagnostics.
- INVALID outcomes: original ARC-006.
- EXPLORATORY/INCONCLUSIVE: ARC-008 and ARC-009 mechanism branches.

Never select a file solely by a later timestamp; use the validity/supersession chain.
