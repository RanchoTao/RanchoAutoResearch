# Reviewer-2 and compute-first filter

## Reviewer-2 rejected (4)

### C03 — rejected

“This is label-noise memorization dressed as a repetition law. Any monotone result
is obvious, while a null result is uninteresting.” A convincing control would need
matched Bayes loss but different epistemic/aleatoric structure, expanding the MVP.

### C08 — rejected

“Feature-aligned teacher errors are already the expected consequence of the
existing subspace and eigendirection theories; a synthetic MLP plot adds little.”
The objection cannot be cheaply answered without a substantive real task.

### C10 — rejected

“The synthetic Gaussian construction determines both collapse and shift failure;
class count and margin will likely explain the result.” CIFAR-LT validation could
help, but then causal ground truth is lost.

### C15 — rejected

“The nearest multilingual-unification paper already varies tokenization and
language association. This is a factorial repackaging, not a new scientific
question.” The remaining delta is too small for an ARC.

## Feasibility rejected (2)

### C05 — rejected

A scientifically meaningful result requires first establishing stable benchmark
exploitation, then long clean continuations and multiple schedules. Tiny models may
not reproduce the regime; larger-model validation pushes the decisive MVP beyond
the preferred compute window. It also overlaps C01's scheduling variable.

### C11 — rejected

The frozen-softmax result is nearly analytic and recent near-tie dilution theory is
already direct. A nontrivial contribution would require realistic long-context
models and retrieval corpora, no longer a cheap decisive test.

## Survivors

C01, C02, C04, C06, and C07 survive. All have a negative outcome that would still
resolve a live boundary, a sub-two-hour MVP, and an early held-out/control design.
