# Frozen evidence snapshots

These files are byte-identical copies of the compact canonical JSON/CSV
artifacts used by the paper. Their original ARC directories remain listed in
`../EVIDENCE_VALIDITY_MAP.md`; hashes for the paper-critical subset are in
`../SHA256SUMS.txt`.

`ARC-006-MATCHING-ONLY/` contains only outcome-blind target assignments and
matching-quality diagnostics that remained unchanged after assay repair. It
does **not** preserve the invalid ARC-006 outcome analysis as valid evidence.
All canonical cross-family outcome values live under `ARC-006R/`.
